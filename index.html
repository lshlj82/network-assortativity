Average degree of a node's neighbours

knn(i) = 1ki Σj aij kj

Add up the degrees of node i's neighbours, then divide by how many neighbours it has. Click a node in the network to compute it.

How r is computed (Newman 2003)

With ejk the fraction of edges joining nodes of excess degree j and k, and qk the excess-degree distribution:

r = Σjk jk (ejk − qjqk)σq2

This equals the Pearson correlation between the degrees at the two ends of an edge. Using excess degree k−1 or plain degree k gives the same value, because a correlation ignores a constant shift. The dashed line in the left plot is ⟨k2⟩/⟨k⟩, what knn would be with no degree correlation at all.

With equal-size groups, r ≈ 2q − 1, so q = 0.5 is random mixing. Unequal groups move the neutral point.

Mixing matrix eij

Fraction of edge ends joining type i to type j. Row sums give ai; for an undirected network bi = ai.
